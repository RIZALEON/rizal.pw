Why uploads are slow: each file goes as one base64 JSON request (about a third larger than the file), with no chunking or resume. Files over 8,000,000 bytes are refused here before anything is sent. The hub stores the file and offers it to admitted nodes; those nodes receive it only on their next sync, so "offered" is not "delivered". On another device, a public browser can't reach the in-app hub at 127.0.0.1; it needs a reachable LAN or peer hub URL and an RGEN token entered above.
