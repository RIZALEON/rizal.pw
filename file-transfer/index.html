How it works

  • Website: static portal hosted from GitHub.
  • Storage: owner-selected RKLOWD folder on iPhone.
  • Local discovery: Bonjour/mDNS on the same Wi-Fi.
  • Remote discovery: authenticated relay presence.
  • Security: HTTPS, per-user tokens, folder-scoped access.

This page is the frontend only. The iOS companion app and relay API must be deployed before transfers work.
