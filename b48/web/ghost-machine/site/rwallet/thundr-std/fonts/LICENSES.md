# Bundled fallback fonts

Official RFONT is the named UI face for this standard. The RFONT file
is not in this pack. Drop `RFONT.ttf` or `RFONT.otf` into this folder;
the CSS already looks for it first.

These four faces are bundled as fallbacks until that file is here.
Each is licensed under the SIL Open Font License, Version 1.1:
https://scripts.sil.org/OFL
