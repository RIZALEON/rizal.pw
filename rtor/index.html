Rtor

signed-update verify

Rtor is the rOS check that refuses any update that isn't signed by Rizal. Each release manifest has a .sig.json next to it. It's an Ed25519 signature made only after Rizal's Face ID approval on his own ЯCASKET device (owner key id e5833fdfbbfe, public key only). The browser checks the exact bytes against that key. Unsigned or tampered files are refused (fail-closed).
