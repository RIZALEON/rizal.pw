RTOR GHOSTCHAIN cryptoclient 0.2.2

Released Nov 20, 2026 (MT). Unsigned builds — signing stays with Rizal (Face ID on the 17e). No keys in any build.

What 0.2.2 does

  • Seeding ↑ and Leeching ↓ side by side for every file, both always on, rates measured from real bytes (idle shows 0).
  • Always-on keepalive: at least 1 KB/s each way per file (runs at 1.5 KB/s), every pass SHA-256 verified.
  • Connects to a peer immediately at start: Neo (RTRACKR backside) → Pixel → Moto on LAN port 4985; public RTRACKR download fallback, then the local drop.
  • Starts by itself: Ubuntu Touch user service, Android foreground service with start-at-boot, Neo launchd.
  • RE-SEED panel reads the live RGHOSTCHAIN and clears only when the sealed, signed RGHOSTKEY block 6 is on-chain.

Measured Nov 20, 2026 10:29 PM MT: Pixel ↔ Neo about 3 KB/s each way per file.
